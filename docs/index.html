ApacheMinaSSHD.NET

A free, open-source .NET SFTP server library and C# wrapper around Apache MINA SSHD. Embed secure SFTP, SCP, and SSH file transfer in your C# applications with zero Java dependencies.

⚠️ Security disclaimer: ApacheMinaSSHD.NET is a wrapper that exposes the Apache MINA SSHD engine through .NET APIs. It provides the building blocks — authentication modules, virtual file systems, algorithm selection — but application-level security depends entirely on how you configure and use these components. You are responsible for choosing strong algorithms, validating authentication callbacks, enforcing path containment, setting appropriate timeouts, keeping dependencies updated, and following security best practices for your deployment environment. See the Security Best Practices guide.

Install via NuGet View on GitHub

dotnet add package ApacheMinaSSHD.NET.Wrapper

Features

Embed a Full SFTP Server in Your .NET App

ApacheMinaSSHD.NET wraps Apache MINA SSHD 2.17.1 through IKVM — zero Java dependencies, no manual setup, just .NET APIs.

🔒

Password Authentication

Fixed, delegate, and composite password authenticators. Full multi-user support with per-session callbacks.

🔑

Public Key Authentication

Fingerprint-based, directory-backed, and OpenSSH authorized_keys authenticators. Supports Ed25519, RSA, ECDSA.

💡

Keyboard-Interactive & MFA

Challenge-response authentication. Combine password + public key for multi-factor authentication policies.

📁

Virtual File System

Root jail isolation, per-user home directories, hidden-file filtering, path traversal protection, and symlink containment.

📦

SFTP & SCP Subsystems

Full SFTP (file open/close/read/write/create/delete/rename/move) and SCP (upload/download/recursive) server support.

📈

Event Listeners & Monitoring

SFTP lifecycle events, session create/establish/close/disconnect, I/O service events, and proxy metadata inspection.

⚙️

Algorithm Configuration

Choose ciphers (AES-GCM, ChaCha20-Poly1305), MACs (HMAC-SHA2), key exchange (Curve25519, ECDH), and host key algorithms.

⏱

Production Defaults

ApplyProductionDefaults and ApplyModernAlgorithmDefaults for conservative security baselines. Configurable timeouts, limits, and banners.

Quick Start

Build Your First SFTP Server in 5 Minutes

Create a console app, add the NuGet package, and paste this code:

Copy
using ApacheMinaSSHD.NET.Wrapper;
using ApacheMinaSSHD.NET.Wrapper.Factories;

var server = AMNetSshServer.SetUpDefaultServer();
server.Host = "127.0.0.1";
server.Port = 2222;
server.Config.ApplyProductionDefaults();
server.Config.ApplyModernAlgorithmDefaults();

var hostKeys = new AMNetSimpleGeneratorHostKeyProvider("hostkey.ser");
hostKeys.setAlgorithm("RSA");
hostKeys.setKeySize(3072);
server.setKeyPairProvider(hostKeys);

server.SetFixedPasswordAuthenticator("admin", "changeme");
server.setFileSystemFactory(
    new AMNetVirtualFileSystemFactory(@"./sftp-root"));
server.setSubsystemFactories(
    new AMNetSftpSubsystemFactory());

server.Start();
Console.WriteLine("SFTP server running on port 2222");
Console.ReadLine();
server.Stop();

using ApacheMinaSSHD.NET.Wrapper;
using ApacheMinaSSHD.NET.Wrapper.Factories;
using ApacheMinaSSHD.NET.Wrapper.Abstractions;
using ApacheMinaSSHD.NET.Wrapper.Abstractions.Models;

var server = AMNetSshServer.SetUpDefaultServer();
server.Host = "127.0.0.1";
server.Port = 2222;
server.Config.ApplyProductionDefaults();
server.Config.ApplyModernAlgorithmDefaults();
server.SetFixedPasswordAuthenticator("admin", "changeme");
server.setKeyPairProvider(
    new AMNetSimpleGeneratorHostKeyProvider("hostkey.ser"));
server.setFileSystemFactory(
    new AMNetVirtualFileSystemFactory(@"./sftp-root"));

var sftp = new AMNetSftpSubsystemFactory();
sftp.addSftpEventListener(new MyEventListener());
sftp.setFileSystemAccessor(new MyFileAccessor());
server.setSubsystemFactories(sftp);
server.Start();
Console.ReadLine();
server.Stop();

class MyEventListener : AMNetSftpEventListener {
    public override void OnOpen(ISshEvent ctx)
        => Console.WriteLine($"Open: {ctx.SshHandle.PhysicalPath}");
    public override void OnWrite(ISshReadWrite ctx)
        => Console.WriteLine($"Write: {ctx.Length} bytes");
}

class MyFileAccessor : AMNetSftpFileSystemAccessor {
    public override bool ShouldIncludeDirectoryEntry(
        ISshFileSystemAccess context) {
        var name = Path.GetFileName(context.RemotePath);
        if (name?.StartsWith('.') == true) return false;
        return base.ShouldIncludeDirectoryEntry(context);
    }
}
