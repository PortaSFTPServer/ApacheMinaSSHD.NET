# SEO and Publishing Notes

Use this checklist when publishing ApacheMinaSSHD.NET to GitHub, NuGet, or a
project website.

## Suggested GitHub Repository Description

.NET/C# wrapper created by SERALYNX LLC for Apache MINA SSHD SFTP and SCP server
features, using IKVM while hiding Java imports from application developers.

## Suggested GitHub Topics

`ssh`, `sshd`, `sftp`, `scp`, `sftp-server`, `scp-server`, `ssh-server`,
`secure-file-transfer`, `file-transfer`, `apache-mina`, `apache-mina-sshd`,
`mina-sshd`, `ikvm`, `dotnet`, `csharp`, `nuget`, `engineering-software`

## Search Phrases to Keep in Project Copy

- .NET SFTP server library
- C# SFTP server
- .NET SCP server
- Apache MINA SSHD .NET wrapper
- Apache MINA SSHD IKVM
- Secure file transfer library for .NET
- SFTP and SCP server features for C#

## Naming Guidance

- Keep `ApacheMinaSSHD.NET.Wrapper` as the primary package developers install.
- Describe the project as a SERALYNX LLC-created wrapper around Apache MINA SSHD.
- Avoid wording that implies Apache Software Foundation ownership,
  sponsorship, or endorsement.
- Keep SERALYNX LLC visible in the README, package metadata, LICENSE, and
  NOTICE files.
