project website.

the team behind **[Porta SFTP Server](https://portasftpserver.com/portable-sftp-server-community-edition/)**,
a portable SFTP server for Windows and Linux trusted by engineering, construction, and
critical infrastructure teams worldwide.

.NET SFTP server library and C# wrapper created by SERALYNX LLC (Porta SFTP
Server) for Apache MINA SSHD SFTP and SCP server features, using IKVM while

## Naming Guidance

- Keep `ApacheMinaSSHD.NET.Wrapper` as the primary package developers install.
- Describe the project as a SERALYNX LLC-created wrapper around Apache MINA SSHD.
- Avoid wording that implies Apache Software Foundation ownership,
  sponsorship, or endorsement.
- Keep SERALYNX LLC visible in the README, package metadata, LICENSE, and
  NOTICE files.
